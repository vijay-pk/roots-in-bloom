# Before & After Results Images Directory

Drop your 2 persons' before-and-after pictures directly into this folder (`public/results/`):

### Person 1:
- **`person1-before.jpg`** or **`person1-before.png`** (Before using Prakrithi Roots)
- **`person1-after.jpg`** or **`person1-after.png`** (After using Prakrithi Roots)

### Person 2:
- **`person2-before.jpg`** or **`person2-before.png`** (Before using Prakrithi Roots)
- **`person2-after.jpg`** or **`person2-after.png`** (After using Prakrithi Roots)

> [!TIP]
> The website will automatically display these images on the **Results** page (`/results`) and homepage sections. Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`.
